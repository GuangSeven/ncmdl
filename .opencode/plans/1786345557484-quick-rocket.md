## 目标

1. **BUG 1**：fallback（无 bracketed paste）终端多行粘贴拆分成多次 read、行间停顿任意时长（实测 0.3s > 200ms 窗口），不得再「截断首行落盘 + 第二行漏入可见队列」；必须给出拒绝提示；截断值绝不持久化。
2. **BUG 2**：确认回车后 0.1s 内输入的 `0\n`（退出）不得再被吞并误判为多行粘贴导致挂死。
3. **功能**：去掉制表符方框菜单，改为纯文本菜单（`ncmdl v1.0.0` + 编号选项），支持 ←/→ 与回车选择、数字即时激活（无需再回车）；选中项红字白底高亮；音质 / 文件名模式 / User-Agent 在向导中改为可切换选项。

关键约束：BUG 1（`MUSIC_U=AAA\n` + 0.3s + `__csrf=BBB\n`）与 BUG 2（`MUSIC_U=FAST\r` + 0.1s + `0\n`）字节形态完全相同，任何固定时间窗口都无法同时满足——第 10 轮修复必须**删除窗口机制**，改用结构判别。

## Part A — 输入引擎修复（删除窗口，改为「回车即确认 + Cookie 形态残留行拦截」）

全部改动在 `src/cli.js`。

### A1. 删除 fallback 窗口机制

- 删除 `FALLBACK_TAIL_MS`（cli.js:239）、`startFallbackTailWindow`（290-296）、`finalizeHiddenInput`（279-288）。
- `hiddenRead` 初始化（464）去掉 `pending`/`pendingTimer` 字段；`resolveHidden`（259-262）去掉 pendingTimer 清理（死代码）。
- `onInputData` 中删除：
  - 挂起窗口分支（350-363，`if (hiddenRead.pending)` 整块）；
  - PASTE_START 时清除 pending 的分支（330-335，只保留 `pasteMode = true`）；
  - 372-384 换行处理改为：rest 检查保留（同 chunk 换行后仍有内容字节 → `rejectMultiLinePaste()`）；rest 仅换行 → **立即 `resolveHidden(buffer.join(""))` 并 `break`**（吸收本 chunk 尾随换行），不再开窗口。
- 重写 221-236 注释块，说明新语义：fallback 回车立即确认；多行拦截点（a）同 chunk rest 检查；（b）「确认后残留行 Cookie 形态拦截」（见 A3）。

### A2. 残留行拦截（Cookie 形态判别，与时间无关）

新增模块级状态：

- `let guardNextVisibleLine = false;` —— 在 `resolveHidden` 内置为 `true`（所有 hidden 路径：普通回车、Ctrl+D、EOF、bracketed finishPaste）。
- `let falloutRestore = null;` —— `{ oldValue }`，见 A4。
- 哨兵：`const PASTE_FALLOUT = Symbol("paste-fallout");`
- 形态正则：`const COOKIE_LINE_RE = /^[^\s=]+=[^\s=]+$/;`（如 `__csrf=BBB`、`MUSIC_U=FAST` 命中；`0`、`y`、UA 字符串不命中）。

**readLine()（428-439）拦截**：出队一行时，若 `guardNextVisibleLine`：
- 空行 → **不清除标记**（守卫保持武装，防晚到残留行漏到后续字段），返回默认值；
- 非空且命中 `COOKIE_LINE_RE` → 清除标记，打印拒绝提示（沿用现有文案 `检测到多行粘贴：Cookie 应为单行文本，本次输入已忽略，请重新粘贴。`），返回 `PASTE_FALLOUT`；
- 其它非空行 → 清除标记，正常返回。

### A3. 各消费点对哨兵的处理

- **interactiveMenu（174-192）**：在调用 `handleMenuChoice` 之前拦截 `PASTE_FALLOUT` → 若 `falloutRestore` 非空则 `config.cookie = falloutRestore.oldValue; await saveConfig(config);`，置空，`continue` 重问菜单。正常选择消费后清空 `falloutRestore`。
- **handleMenuChoice case "3"（85-123）**：两个写 Cookie 分支（97-100 y/n→n 分支、108-113 resolveCookie 分支）在保存前记录 `falloutRestore = { oldValue: config.cookie }`。`targetInput`（86-90）与 `keepCookie`（95-96）遇哨兵 → 重问。
- **case "5"（129-138）** `confirm` 遇哨兵 → 重问。
- **setupWizard（478-499）**：每个字段（UA/dir/quality/pattern）取到 `PASTE_FALLOUT` 时 → 重问 Cookie（沿用 481-484 的 while-null 循环）→ 再重问该字段（重试循环）。向导所有字段在保存前（496）才落盘，天然不落截断值。

注：A3 先于 Part B 单独成立（菜单仍走 cooked `askVisible` 时 readLine 拦截即覆盖全部场景）。

## Part B — 新交互菜单（raw-mode 选择器）

### B1. `askMenu(options, { title, defaultIndex, prompt })` 组件（`src/cli.js`）

TTY 且 raw 模式可用时使用；**非 TTY 完全退回现有 cooked 路径**（管道/文件测试不受影响）。

- **渲染**：纯文本，固定行数（title 1 + 空行 1 + 选项 N + 空行 1 + 提示行 1）。选中行整行 `\x1b[31;47m…\x1b[0m`（红字白底）。箭头/Enter 后重绘：光标移到菜单顶（`\x1b[<rows>A`）逐行重画。
- **按键**：
  - 数字 `0-9` → **仅当累积缓冲区为空时**（会话首个字符）即时激活对应选项；越界数字打印 `无效的选择，请重新输入。` 并停留。
  - `\r`/`\n` → 确认当前高亮；**主菜单无默认项时裸回车为 no-op**（保护「粘贴后习惯性回车」，见测试 282-306）。
  - `\x1b[C`/`\x1b[D`（左右）、`\x1b[A`/`\x1b[B`（上下）→ 移动高亮并重绘；转义序列用与 hidden 相同的 escSeq 累积法，并复用 `isPasteSeqPrefix` 丢弃无关序列、识别粘贴标记（B4）。
  - `\u0004` → `stdinEof = true` + resolve `""`（走现有「输入已结束，退出。」路径，测试 446-458）。
  - `\u0003` → `exit(130)`。
- **队列先占**：进入时若 `lineQueue` 非空 → 出队首行（复用 A2 的守卫检查：armed + Cookie 形态 → 打拒绝提示并 resolve `PASTE_FALLOUT`），否则进入 raw 等待（对应测试 194-207 的 `4\n0\n` 单 chunk 流）。
- **数字即时激活后的同 chunk 换行吞并**：数字 resolve 后，本 chunk 紧随的 `\r`/`\n` 直接吸收（并置 `prevChar` 以配合 389-392 的 `\r\n` 去重），避免空行落入下一个提示。
- **累积缓冲**：非命令字符累积到 `picker.buffer`；Enter 时若缓冲命中 `COOKIE_LINE_RE` 且守卫 armed → 打拒绝提示 + resolve `PASTE_FALLOUT`；否则 resolve 缓冲文本（走现有无效选择语义）。缓冲非空时数字不再激活（防 `__csrf=123` 误触选项 1）。

### B3. 向导字段改为选择器（TTY）

## 测试

### 新增（PTY，`test/cli.test.js`，非 Windows 环境执行）

1. **BUG 1 菜单 case 3 复现**：`3\n` → `abc\n` → `n\n` → 粘贴 `MUSIC_U=AAA\n`（无标记）→ `{ after: 0.3, send: "__csrf=BBB\n" }` → trigger `检测到多行粘贴` → `0\n`。断言：退出码 0、config.cookie 仍为旧值、无 `无效的选择`、有 `再见！`。
2. **BUG 1 向导复现**：`2\n` → 粘贴 `MUSIC_U=AAA\n` → `{ after: 0.3, send: "__csrf=BBB\n" }` → trigger `检测到多行粘贴` → `MUSIC_U=OK\r` → UA/目录/音质/模式各 `\n` → `0\n`。断言 cookie=`MUSIC_U=OK`、UA 未被污染。
3. **BUG 2 在 0.1s（窗口内）**：`3\n` → `abc\n` → `n\n` → 粘贴 `MUSIC_U=FAST\r` → `{ after: 0.1, send: "0\n" }`。断言退出码 0、cookie=`MUSIC_U=FAST`、无 `检测到多行粘贴`（现有 879-901 用 0.3s，只测了安全余量）。
4. **fallback 单 chunk 多行（无标记）**：一次写入 `MUSIC_U=AAA\n__csrf=BBB\n` → `未获取到新 Cookie`、旧 Cookie 保留。
5. **选择器**：`请选择功能` → `\x1b[C\r`（右移+回车选中选项 2 向导）；数字即时激活：`4`（不带 `\n`）→ 执行查看配置；向导音质选择器：trigger `请输入默认音质` → `2` → 断言 config.quality 变化；`\u0004` 菜单 EOF 仍打印 `输入已结束，退出。`。
